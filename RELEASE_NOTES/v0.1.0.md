# 🚀 Release v0.1.0 – Initial Playable Prototype

This is the first public release of **Dojo City Builder**, integrating Unity and Dojo for on-chain gameplay.

## Features
- Tile-based grid with purchase interaction.
- Player contract setup and initialization flow.
- UI buttons for tile purchase and upgrades.
- On-chain calls using auto-generated Dojo bindings.
- Unity-based visual feedback and tile highlighting.

## Tech Stack
- Unity 2022
- Dojo (StarkNet), katana devnet
