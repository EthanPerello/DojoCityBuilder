# 🛠️ Release v0.2.0 – Refactor and Reset Logic

This release refactors core systems and prepares the game for world resets and contract upgrades.

## Highlights
- ✅ Rewrote all Unity logic using modular Dojo bindings.
- ➕ Added support for `reset_player_data` and `remove_building`.
- 🔄 Updated `Scarb.toml`, `manifest_dev.json`, and contract metadata.
- 💼 Migrated from legacy `JsonRpcClient.cs` to auto-generated contracts.

## Removed
- ❌ Deleted UnityMainThreadDispatcher, old TileManager, and GameStateManager.
- 🗑️ Removed all static LFS libraries and native C# Dojo wrappers.

## Compatibility
- Built for `city-builder-v2` world with upgraded seed and metadata.
