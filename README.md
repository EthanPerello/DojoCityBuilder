# On-Chain City Builder Game

A blockchain-integrated multiplayer city-building simulation developed in Unity using the Dojo engine and StarkNet. Originally built during the Dojo Game Jam, now expanded into a full-featured game.

## 🚀 Features

- Multiplayer city simulation with on-chain player data
- Players can purchase land tiles and construct various building types
- Dynamic economy: resident happiness & income affected by building placement
- Smooth camera controls, building UI, leaderboard, and menu systems
- All game logic recorded on-chain via Dojo (StarkNet)

## 🧰 Tech Stack

- Unity (C#)
- Dojo / Cairo / StarkNet
- On-chain asset ownership
- WebGL build for browser-based gameplay
